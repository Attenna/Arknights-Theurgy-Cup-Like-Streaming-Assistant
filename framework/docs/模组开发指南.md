# 模组开发指南

演播室2 的模组系统允许你（或任何用户）为直播间开发**自定义直播场景**，以及附加逻辑与数据。
模组是放在项目 `mods/` 目录下的一个独立文件夹，包含清单、脚本与场景资源。

---

## 1. 目录结构

```
mods/
├── mods.json                 # 模组启用注册表（在此登记要加载的模组 id）
├── mod_template.gd           # 模组脚本模板
└── your_mod/                 # 你的模组文件夹（名称即模组目录名）
    ├── mod.json              # 模组清单（必需）
    ├── mod.gd                # 模组入口脚本（必需）
    ├── scenes/               # 场景（直播场景放这里）
    │   └── live_scene.tscn
    ├── scripts/              # 其他脚本（可选）
    ├── assets/               # 模组自有资源（可选）
    └── data/                 # 模组自有数据（可选）
```

---

## 2. 清单文件 `mod.json`

```json
{
    "id": "your_mod",
    "name": "你的模组",
    "version": "1.0.0",
    "author": "你的名字",
    "description": "模组简介",
    "dependencies": [],
    "load_priority": 0,
    "autoload": true,
    "scenes": ["scenes/main_menu.tscn"],
    "streaming_scenes": [
        {
            "id": "your_live_scene",
            "name": "你的直播场景",
            "scene": "scenes/live_scene.tscn",
            "description": "这个场景在直播中显示什么"
        }
    ],
    "data_files": ["data/config.json"],
    "asset_paths": ["assets/"]
}
```

字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String | 模组唯一标识，建议与文件夹名一致 |
| `name` / `version` / `author` / `description` | String | 展示信息 |
| `dependencies` | Array | 依赖的其他模组 id，需先于本模组加载 |
| `load_priority` | int | 初始化顺序，数值越小越早 |
| `scenes` | Array | 普通场景列表（相对模组目录） |
| `streaming_scenes` | Array | **直播场景**列表，见下 |
| `data_files` / `asset_paths` | Array | 模组自有数据 / 资源目录 |

### `streaming_scenes` 条目

| 字段 | 说明 |
|------|------|
| `id` | 直播场景唯一标识，控制面板切换时使用，需全局唯一 |
| `name` | 显示名称（会出现在控制面板的「模组直播场景」中） |
| `scene` | 场景文件路径，相对模组目录 |
| `description` | 悬停提示 |

> 被 `mods.json` 登记为启用的模组，其 `streaming_scenes` 会被自动注册，并在控制面板列出、可一键切换。

## 3. 入口脚本 `mod.gd`

继承 `ModInterface`，按需重写生命周期回调：

```gdscript
extends ModInterface

func get_metadata() -> ModInterface.ModMetadata:
	var meta = ModInterface.ModMetadata.new()
	meta.id = "your_mod"
	meta.name = "你的模组"
	meta.version = "1.0.0"
	meta.streaming_scenes = [{
		"id": "your_live_scene",
		"name": "你的直播场景",
		"scene": "scenes/live_scene.tscn"
	}]
	return meta

func on_load() -> bool:
	# 加载时调用，返回 false 会中止加载
	return true

func on_initialize() -> bool:
	# 所有模组加载、内容就绪后调用
	return true

func on_activate() -> void: pass
func on_pause() -> void: pass
func on_unload() -> void: pass
```

## 4. 直播场景：继承 `ModScene`

模组的直播场景根节点脚本应 `extends ModScene`（全局类，位于 `core/mod_scene.gd`），
即可自动获得当前直播数据与信号。

```gdscript
extends ModScene

@onready var name_label: Label = $NameLabel

func _on_mod_scene_ready() -> void:
	# 场景就绪：用 scene_name / scene_id / mod_id 做初始化
	name_label.text = scene_name
	_refresh(get_current_player())

func _on_player_changed(player_data: Dictionary) -> void:
	# 控制面板确认选手后触发
	_refresh(player_data)

func _refresh(player_data: Dictionary) -> void:
	name_label.text = str(player_data.get("name", "未选择"))
```

### ModScene 提供的接口

| 成员 | 说明 |
|------|------|
| `mod_id` / `scene_id` / `scene_name` | 由 ModLoader 注入的身份信息 |
| `_on_mod_scene_ready()` | 场景就绪回调（重写） |
| `_on_player_changed(data)` | 当前选手变化回调（重写） |
| `_on_announcer_changed(data)` | 当前解说变化回调（重写） |
| `get_current_player()` | 当前选手数据（`userdata/players/current_player.json`） |
| `get_current_announcer()` | 当前解说数据 |
| `get_players()` / `get_teams()` | 全部选手 / 队伍列表 |
| `get_team_by_id(id)` | 按 id 取队伍 |
| `player_changed` / `announcer_changed` | 可连接的信号 |

### 资源路径约定

- 模组自有资源用 `res://mods/<模组目录>/...` 引用。
- 共享资源（字体、着色器等）直接引用核心资源，例如
  `res://shared/fonts/SourceHanSerifSC-Bold.otf`。
- 直播画面基准分辨率为 1920×1080，场景坐标系可用绝对定位。

---

## 5. 启用与调试

1. 在 `mods/mods.json` 的 `mods` 数组中登记你的模组 id：

   ```json
   { "mods": ["example_mod", "your_mod"] }
   ```

2. 启动程序，控制面板底部「模组直播场景」会列出你的场景，点击即可切换。
3. 控制台会输出 `[ModLoader] ...` 日志，便于排查加载问题。

---

## 6. 参考实现

完整可运行示例见 `mods/example_mod/`：

- `mod.json`：声明了一个直播场景 `example_live_scene`
- `live_scene.tscn`：直播画面（背景 + 标题 + 选手/队伍/分数）
- `live_scene.gd`：继承 `ModScene`，实时刷新数据

可直接复制该目录作为你自己的模组起点。
