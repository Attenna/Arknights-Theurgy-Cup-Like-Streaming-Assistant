# 控制面板插件约定（基底 + 二级面板）

> 简要说明控制面板的「基底 + 二级面板」插件架构与开发约定。
> 参考实现：`mods/control_panel_base/`（基底）、`mods/scene_manager_panel/`（二级面板示例）。

---

## 1. 架构总览

```
main 壳（src/scripts/main/main.gd）
   │  装载 slot="main_window" 的唯一面板
   ▼
[control_panel_base]  ── Window 基底（骨架 + 二级面板装载槽）
   ▲   mount_panel / unmount_panel（幂等 API）
   │
[scene_manager_panel]  ── slot="control_panel" 的二级面板
   （plugin.json 声明 dependencies: ["control_panel_base"]）
```

- **基底**只提供窗口骨架与装载机制，不含任何业务功能。
- **二级面板**才是功能提供方（场景管理、模组管理、编辑器……可并存多个）。
- 二者通过 `PluginManager` 的**依赖解析**保证加载顺序：基底先于全部二级面板。

## 2. 职责与约定

### 基底插件（control_panel_base）

| 项 | 内容 |
|------|------|
| 清单声明 | `provides.panels` 中一条 `slot="main_window"`（`main` 壳只认这个槽位） |
| 启动装载 | 面板根脚本 `_ready` 时全量装载 registry 中 `slot="control_panel"` 的所有面板（兜底） |
| 对外 API | `mount_panel(panel_id, packed, name)` / `unmount_panel(panel_id)`，均幂等 |
| 查找方式 | 根脚本加入组 `control_panel_base`，二级插件用组查找定位基底 |

### 二级面板插件（如 scene_manager_panel）

| 项 | 内容 |
|------|------|
| 清单声明 | `dependencies: ["control_panel_base"]` + `provides.panels` 一条 `slot="control_panel"` |
| 挂载 | `on_enable` / `on_after_reload` → 组查找基底，调用 `mount_panel`；基底尚未创建时静默跳过（启动早期由基底的 `_ready` 全量装载兜底） |
| 卸载 | `on_disable` / `on_unload` → 调用 `unmount_panel` |
| 时序保证 | 启动：基底 `_ready` 扫描；热重载二级：`on_after_reload` 幂等重挂；热重载基底：级联重载二级后重挂 |

## 3. 场景切换（scene_manager_panel 的做法）

- 列表数据：`SceneDirector.get_scenes_by_type("live")`（内核实时维护，新场景插件加载后重载面板即可刷新）。
- 切换：按钮直接调用 `Kernel.scene_director.switch_to(scene_id)`，**不依赖** main 壳的 `transition_requested` 旧约定。
- 高亮：连接 `SceneDirector.scene_changed(from, to)` 信号，驱动按钮选中态。

## 4. 新增一个二级面板的最小步骤

1. 复制 `mods/scene_manager_panel/` 为新目录，改 `plugin.json` 的 `id` / 面板 `id`（保持 `slot="control_panel"` 与 `dependencies`）。
2. 实现面板场景与脚本（普通 `Control` 即可，无需继承内核基类）。
3. `plugin.gd` 保留挂载/卸载约定（改 `PANEL_ID` 常量即可）。
4. 放入 `mods/`，启动即自动装载；缺失基底时会被依赖解析阻塞并在模组面板显示原因。

## 5. 检验方式

- **F5**：控制面板窗口自动弹出并含「直播场景」列表，点击即切换直播场景。
- **直连场景**（无控制面板时检验直播场景插件）：项目设置 → 运行 → 自定义参数填
  `-- --scene <场景id>`，或命令行 `Godot_console.exe --path <项目> -- --scene streaming_arena`。

> 已知边界：无头模式下会出现 `Window spawned at invalid position`（无真实屏幕所致），窗口运行无此问题；
> 基底面板自身的热重载需重启生效（main 壳持有的 Window 实例不会重建），二级面板热重载完整可用。
